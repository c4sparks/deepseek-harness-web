# 01 · 产品需求与功能

> 阶段：需求功能 · 维护者：插件维护者

## 定位与范围
dsh 的 VS Code 轻量前端（自绘聊天 + 可选 dsh 网页，经 dsh 原生 RPC，不改 dsh）。

| 范围 | 内容 |
|---|---|
| 做 | 聊天（流式/思考/工具/审批/提问/图片/文件/markdown）、右键处理代码、模型/推理、权限预设、工作区/会话、消费记录、dsh 网页兜底 |
| 不做 | 不含 dsh 业务逻辑；不存不读 API key；完整能力用 dsh 上游网页 |

## 功能清单与要点
| ID | 功能 | 入口/要点 | 底层 dsh |
|---|---|---|---|
| F1 | 聊天 | Activity Bar 进入；流式逐字、思考折叠、图片/文件/markdown、审批/提问卡（`$events` 本地应答） | session/prompt + follow + `$events` |
| F2 | 模型/推理 | 🤖 弹层 + `/model` 斜杠入口；切模型按该模型 `reasoning.defaultEffort` 走，effort 按模型单选；两级都算不出时退到 `Default`（提供方默认，不传 effort） | modelCatalog/selectModel |
| F3 | 权限 | 🛡 直列后端预设；danger 走自绘确认；经 `commands/execute` 下发 `/permission` | permissions + commands/execute |
| F4 | 工作区/会话 | 当前 = workspace/follow `updatedAt` 最新（不另存）；标题栏树面板恢复；建会话必须归属工作区，无可用工作区时引导选/建，绝不静默落「未分组」 | workspace/follow、session/* |
| F5 | 右键处理 | 处理/提问/@ 复用共享会话 | 共享会话 |
| F6 | 消费记录 | usage 透传（缺失不补 0）、≤500 裁剪、今/昨/周/月分组报告 | assistant/message usage |
| F7 | dsh 网页 | 本地打开经认证代理同源页；浏览器兜底 | dsh web HTTP / WS |
| F8 | 动态启动 | 打开自动探测/自启 | dsh CLI |
| F9 | 会话模式 | 输入区层叠图标弹层；空白会话可选，已有会话只读；内置模式本地显示名、自定义用 dsh name（v0.1.4 · dsh 0.1.2-rc.1 新增） | agentPresets/list + select |

## 关键流程
- 服务生命周期：空闲 → 探测既有(复用) ｜ 未中 → Node 检查 → 自启(`web --no-open --port 0`) → 解析 stdout → 验信封 → 就绪。
  多入口（聊天初始化/工作区/本地打开）共享同一次启动：`ensureRunning()` 单飞等待，不会重复拉起，也不会在启动窗口期被并发入口打断。
- 一轮对话：发送 → 确定会话 → `session/prompt`(queue) → follow 事件流(打字机/思维链/工具/结束)；审批/提问经 `$events` 下发，聊天内应答后 agent 继续 → 写 usage + statsbar。
- 权限切换：选预设（danger 先确认）→ `commands/execute` `/permission <preset>`。
- 审批/提问：rc.1 由 `$events`（/api/remote.mux）投递，插件维护监听流并在聊天卡片内应答
  （`$events/result`）；未命中/过期时提示去上游网页，停止用 `session.cancel`。

## 字段要点
- usage：uncachedInputTokens/outputTokens/cacheReadTokens/cacheWriteTokens/reasoningTokens[/totalTokens]；命中率 = cacheRead/(uncached+cacheRead)，缺字段不显示。
- 当前工作区：workspace/follow snapshot 的 `updatedAt` 最新者。
- 会话归属：新建会话绑定工作区（显式选 / 当前 / 自动默认 = `updatedAt` 最新或当前文件夹）；三者皆无抛 `DshNoWorkspaceError`（code `NO_WORKSPACE`）引导选/建，不再回退 `createSession({})`（会落「未分组」）。内嵌上游 dsh 网页 iframe 由 dsh 核心自建会话并归组，不受本条约束。【v0.1.7(dev) · dsh 0.1.2-rc.1】

## 配置项
| 键 | 默认 | 说明 |
|---|---|---|
| dsh.port | 0 | 0=自动（推荐；rc.1 只有插件自启才能捕获 dsh web URL 完成登录）；>0 指向既有实例，仅当该实例无需鉴权或插件已持有 authUrl 时可用 |
| dsh.cliPath | "" | 显式 CLI（优先级最高） |
| dsh.repoPath | "" | dsh 源码仓根（仅开发调试；优先级次之） |
| dsh.webArgs | [] | 插件自启 `dsh web` 时追加的额外 CLI 参数（字符串数组）；不覆盖固定参数 `web --no-open --port 0`，只负责 `--host` / `--trusted-host` 等调试参数 |
| dsh.retainContextWhenHidden | true | 切走后保留 DSH 面板/聊天状态（开=不重载、更占内存；关=省内存、切回重载） |

## 命令与入口
容器 `dsh` 下的视图 `dsh.launcher`。命令 `dsh.*`：workspace/open/applySelected/askSelected/sendToDsh/openInBrowser/openInEditor/reload/newSession/usage/closeSidebar/moveToEditor。激活：`onStartupFinished`、`onWebviewView:dsh.launcher`（随启动激活，无需逐一 onCommand）。当前未注册快捷键。

## 版本能力总览
| 版本 | 状态 | 能力要点 |
|---|---|---|
| dsh 0.1.2-rc.1 | 当前支持 | 斜杠 + args 信封；follow/page；workspace/follow；`$events` 聊天内审批/提问；cookie 鉴权；本地代理内嵌网页；`dsh.webArgs` |
| dsh 0.1.2-alpha.3 及更早 | 历史（不再兼容） | 点号方法 + 平铺 payload；events.mux；`/api/respond`；无 cookie 鉴权 |

说明：代码当前只按 rc.1 实现，不做双协议自动切换；需要旧版 dsh 时使用当时配套的旧插件包。

## 非功能
性能：打字机不卡 UI、长会话增量渲染、usage≤500。安全：仅发 127.0.0.1、不自动传整文件、不存读 key、danger 自绘确认、`editor.edit` 写回、DOMPurify。可维护：dsh 协议集中在 `src/dsh/`（门面 index.ts），UI 面板在 `src/dshPanel.ts`。

## 已知限制 / 后续
当前只支持 dsh `0.1.2-rc.1`；历史版本差异见 README「版本兼容」与 04 的历史章节。
