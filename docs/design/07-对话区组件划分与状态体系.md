# 07 · 对话区组件划分与状态体系

> 主题：webview 前端"不一个文件写到底"——按**对话区回复的类型**为大类→细分拆组件；并统一**状态/加载**的口径（模块在 `webview/chat/core/states.ts`）。
> 参考：Claude / ChatGPT / Copilot 的行类型划分与状态模型。

**★ 重点（UI 规范）：**
1. **只有“标签(label/tag)”永不换行**（思考/网页搜索/提问/Pwsh/工具标题…，`white-space:nowrap; word-break:keep-all`）；标签后的正文自适应省略、展开正文可换行（§4.5）；
2. 链成员(思考/工具)统一 **Disclosure 交互**：收起=单行箭头行、点开看正文（§4.1）；
3. 工具成功(ok)**不打勾**；error 才显红、running 转圈、stopped 灰（§4.1）。

## 1. 对话区行类型 → 组件文件

| 大类（行类型） | 细分子件 | 文件 |
|---|---|---|
| 用户消息 | 气泡/引用 chip/图片 | `components/message/UserRow.ts` |
| assistant 回复 | 过程链(`chain/*`) + 正文 + 终态角标 + 动作条 | `components/message/AssistantRow.ts` |
| └ 过程链（思考/工具折叠窗口） | 折叠头、明细 | `components/chain/Chain.ts` |
| └ 思考行 | Disclosure：收起=一行`思考+首行摘要`，展开=全文(流式自动滚底) | `components/chain/ReasoningRow.ts` |
| └ 工具行 | Disclosure：收起=一行`标题+摘要预览+状态`，展开=真实输出 + 原始参数(不翻译) | `components/chain/ToolRow.ts` |
| 审批卡 | 允许/拒绝 | `components/message/ApprovalRow.ts` |
| 提问卡 | 选项/自由输入/提交 | `components/message/QuestionRow.ts` |
| 通知/命令结果行 | 红点/正常 | `components/message/NoticeRow.ts` |
| 消息动作条 | 时间/复制/重生成/TurnStats | `components/message/meta.ts` |
| 消息列表（分发） | 按 row.kind 分派 + 智能滚动 | `components/message/MessageList.ts` |

编排壳（`components/app.ts`）只做挂载，不再堆积行渲染。数据模型（`core/store/chat.ts`）：user/assistant/approval/question/notice 五种行；assistant 行挂扁平 `chain[]`(reasoning/tool 交错)。

## 2. 状态体系（`core/states.ts` 单一来源）

| 分类 | 枚举/常量 | 落地组件 | 状态 |
|---|---|---|---|
| 思考指示器 | `GenerationPhase.Thinking` + 动词 | Chain 进行中头 / ReasoningRow live | ✅ |
| 生成状态 | `Generating` + 正文光标 `.is-typing::after` | AssistantRow | ✅ |
| 占位/骨架 | `PlaceholderKind`(Welcome/FirstReply/Composer/SlashHint) | 欢迎页建议卡、输入 placeholder、斜杠 ghost | 部分 |
| 打字指示器 | `TypingIndicator`(Caret/Dots) | Caret ✅；Dots [未接] | 部分 |
| 过渡状态 | `BusyKind`(Loading/Switching/Sending) | 历史装载/切会话禁用(`.composer.is-busy` + `.composer-busy` 提示行，宿主恢复前发 `busy loading`) | ✅ |
| 任务/工具状态 | `ToolState`(running/ok/error/stopped) | ToolRow / Chain | ✅ |
| 过程状态 | `ChainState`(Active/Settled) | Chain 头 | ✅ |
| 趣味动词 | `SpinnerVerbs`(thinking/tool/loading) | Chain `LiveVerb` | ✅(thinking)；tool/loading 可复用 |
| 语音类 | `VoiceState` | — | [未接线：文本插件无语音] |
| 资源负载 | `ResourceState` | — | [未接线：需宿主 context 压力投影] |
| 终态别名 | `TerminalState` | assistant status/end-note | ✅ |

规则：状态字面量只在 `core/states.ts` 出现一次；组件 import 使用；未接线项不预留死代码。

## 3. 维护约定
- 加一种“对话区出现的块”→ 新增/归属到对应行文件 + 在 MessageList 分发；链成员（思考/工具/上下文注入）走 `chain/`。
- 样式按功能模块化：`styles/chain.css`(过程折叠/思考/工具行)、`styles/state.css`(过渡 busy 等)、`chat.css`(base/消息/标题栏/弹窗/composer 主体，`@import` 引入子模块)。继续拆分 message/composer 为独立文件时沿用同一方式。
- 不要为了小改重排大文件；状态字面量只在 `core/states.ts` 出现一次。

## 4. 行级 UI / 交互规格（实现按此对齐）

### 4.1 过程链成员（`chain/`，Disclosure 统一交互）
所有链成员（思考/工具）是同一套 Disclosure 形态：**收起 = 单行头部（▸/▾ + 图标 + 标题 + 状态），点行/箭头展开正文**。

| 成员 | 收起(单行) | 展开 | 流式中 |
|---|---|---|---|
| 思考行 ReasoningRow | `▸ 思考 + 首段一行(宽不足省略)` | 全文 | 默认自动展开、独立容器(高封顶 160px)自动滚底；定稿/可再收起 |
| 工具行 ToolRow | `▸ 图标 + 标题(Pwsh/网页获取/…) + 摘要(单行自适应) + 状态`（成功 ok 无角标） | 展开=真实输出(tool/result，原样) + 原始参数(pretty JSON)；**不自行翻译/不编造展示** | running 时头部状态转圈 |
| 链头 Chain | 进行中：动词轮换(LiveVerb)；定稿：`N 次工具调用 · M 条消息` 折叠行 | 点击展开所有成员 | 定稿默认收起，可再展开 |

状态角标规则：running=蓝转圈；error=红(warning)+错误码；stopped=灰；**ok=无角标**（成功完成本身不再打勾，避免无意义绿勾）。

### 4.2 非链消息行（`message/`）
| 行 | 交互要点 |
|---|---|
| user | 右侧气泡；meta 仅复制(无重生成) |
| assistant | 上方 `<Chain/>`；正文流式 `.is-typing` 光标；末 meta 复制/重生成/用量/用时(hover 或最新常显) |
| approval | 允许/拒绝按钮，应答即删卡 |
| question | 选项/自由输入 + 回答/取消；取消先禁用等宿主确认再删 |
| notice | 命令结果：失败红点红字/成功常规色 |

### 4.3 过渡/占位
- 恢复历史/切工作区：宿主恢复前发 `busy:loading` → composer `.is-busy`(透明禁输入) + `.composer-busy` 转圈提示；恢复后清空。
- 欢迎/placeholder/斜杠 ghost 沿用既有。

### 4.4 视觉基调
hairline 边框 + 低透明叠层(深浅通吃) + 语义色状态点 + 克制 hover；链/思考/工具行字体层级：标题加粗、内容次级淡字；参数值等宽可滚动。**像素级数值（宽/高/间距/上下左右 padding/margin/圆角/字号/行高/动效）见 `docs/design/08`。**

### 4.5 排版硬规则（UI 规范，遵循）
- **“标签(label/tag)”永不换行**：指标识类型的短词（思考 / 提问 / 上下文注入 / Pwsh / 网页搜索 / 工具标题…）作为整体不可断词/折行 → `white-space:nowrap; word-break:keep-all`。涉及类：`.chain-row-title`、`.chain-tool-title`、`.chain-summary-text` 等。
- **收起态：标签后的正文默认显示一行**（不做整段折行/全显），占满剩余宽度(`flex:1 1 auto; min-width:0`)，**宽度不足才省略(ellipsis)**、不做固定字数上限——编辑器/宽面板一行能容更多就显示更多；**全文一律靠展开箭头查看**。右侧状态/错误码固定(`margin-left:auto`)。对应 `.chain-row-preview`(nowrap+ellipsis)。
- **展开的正文/参数允许换行**（可读区域内折行；JSON 可横向滚动）。约束只针对“标签不换行”，不限制正文。
- 收起行单行由标签 + 自适应正文共同构成（标签不换 + 正文省略），不会把标签挤断。
