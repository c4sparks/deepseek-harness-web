# 03 · 界面交互与用户手册

> 阶段：设计/交互/用户 · 维护者：插件维护者

## 布局

侧边栏聊天视图 `dsh.launcher` 顶部为标题栏，下方消息区(flex:1) + 输入区(composer) + 底部 statsbar。

标题栏有两种实现（同一常量 `TITLEBAR_MODE` 切换，当前默认 `nativeTitle`；**不自动判宿主**——nativeTitle 即原生、selfDrawn 即自绘）【v0.1.5 · dsh 0.1.2-rc.1】：
- 原生标题栏：由宿主在 webview 视图头渲染（`menus.view/title`）。宿主渲染得出原生头即生效（默认）；渲染不出（如 sidex 等）则切 `'selfDrawn'`。
- 自绘标题栏：页面内 `#titlebar`，跨宿主通用；渲染不出原生头的宿主用它。

自绘标题栏按钮自左向右：`> 工作区名`（指示，悬停显全称）、spacer、📁（工作区选择）、＋（新会话）、浏览器打开/刷新（仅 DSH 面板打开时）、本地打开、移到编辑器、⋯（消费记录）。👁 关闭侧栏预留但默认隐藏。详见 docs/details/03。

## 视觉与组件规范
| 条目 | 规范 |
|---|---|
| 色彩 | 全用 `var(--vscode-*)`，禁硬编码；标题栏背景取 `--vscode-sideBar-background`（与原生 view/title 同底色），边框 `--vscode-panel-border`；头像 `--vscode-badge-background`（中性灰，无渐变） |
| 图标 | 标题栏用内嵌 Codicon（`codicon.css` base64 字体）；输入区权限/模型/模式用内联 SVG currentColor |
| 标题栏按钮 | 命中区 24×24，Codicon 16px；hover 灰底 `rgba(128,128,128,0.22)`；隐藏项不占位 |
| 标题栏间距 | `#titlebar` flex `gap:2px`；spacer `flex:1 1 auto`；📁/⋯ 等图标容器 `flex:none`（防窄栏被压缩溢出叠邻居） |
| 工作区名指示 | `> 名`：名称宽裕时全显，过长省略号 + 悬停 title 显全称；上限 64% |
| 工作区下拉 | 页内浮层，`position:fixed` 铺满侧栏宽（窄侧栏也可见）；顶部搜索框 + 当前工作区行 + 工作区树（可展开会话）＋ 底部「新建工作区…」 |
| 会话行 | 当前会话：✓ + 「当前」；运行中：sync + 「运行中」；其余：history + 「恢复」；长名省略 + 悬停全称 |
| 面板态联动 | 默认只显示「本地打开 ⬇」；点它打开 DSH 面板后切为「浏览器打开 🌐 + 刷新 ⟳」（原生按钮显隐由 `dshPanelOpen/dshViewMode` 上下文同理控制） |
| 输入栏布局 | `#inputbar` flex 垂直居中，图标按钮 22×22 `flex:none`，组间 gap 4px；发送/停止 24×24 圆形居右 |
| 输入区收窄 | `.sel-group` `flex:0 1 auto; min-width:22px`（保图标不被压小）；文字 label 无死上限，宽时全显、窄时省略号缩到 0；图标固定等距、不叠发送按钮 |
| 输入区边框 | `#inputbox` 常显 1px 边框（主题变量优先）；聚焦换 `--vscode-focusBorder`；`#composer` 无顶部分割线 |
| 图标按钮 hover | ＋/权限/模型/模式 hover 圆角灰底（`rgba(128,128,128,0.28)`），active 用 0.35 |
| 弹层配色 | 权限/模型/模式选项 hover 与选中统一用主题列表色（`--vscode-list-hoverBackground` / `--vscode-list-activeSelectionBackground`），不用按钮蓝，浅色模式清晰【v0.1.5】 |
| 通用弹窗 | `showDialog()`(modal.ts) 统一确认/提示；danger 确认带 ack 勾选 |
| 发送/停止 | 发送=内联 SVG 细线上箭头，停止=内联 SVG 方块；CSS 用 stop 类切换，stop 时按钮红底 |
| 消息渲染 | 用户右/dsh 左；markdown 过 DOMPurify；图片内联 max-height 240px；思考折叠「已思考 · N 步 · N 工具」。悬停动作：提问行仅复制；回答行 复制/重新生成 |
| 回复用量/用时 | 每条已完成回答的内容下方**默认常显**两个图标按钮（📊 用量、⏱ 用时，图标旁带数值），点击**向上**弹官方同款弹窗【v0.1.6】：用量 = 累计投影差分（未缓存输入+缓存读+输出=本轮用量；另列提供方/模型、缓存命中、其中推理）；用时 = 本轮总用时/TPS/TTFT（TTFT、TPS 取累计投影 ttftMs/ttftSteps、decodeMs/decodeTokens 差分；总用时取服务端 turn 事件墙钟）。历史恢复行同样显示（用量=该条 assistant/message 自带 usage；用时由快照事件时间推算）。实现：`webview/chat/components/TurnStats.ts` + `src/dsh/cumulative.ts` |
| 已知限制（历史计时） | 历史恢复的 ⏱ 弹窗里 TTFT/TPS **依赖快照保留 `step/start` 与 `text-delta` 时间**；若上游把历史压缩成只剩 `assistant/message`，TTFT/TPS 无数据可算 → 显示 “—”，**不伪造**（用量/总用时仍可显示） |
| statsbar | 底部仅一条官方累计 statsbar（与回复用量相互独立） |

## 消息桥接（webview ↔ 扩展）
| 方向 | type |
|---|---|
| webview→ext | ready/chatSend/cancel/approvalResponse/questionResponse/questionCancel/chatSelectPermission/chatSelectModel/chatSelectMode/pickFile/copy |
| ext→webview | chatChunk/chatReasoning/chatActivity/chatApproval/chatQuestion/questionClosed/chatDone/chatHistory/chatInfo/filePicked/draft/clear |

握手：webview 发 `ready` 后扩展才推 `chatInfo`（避免切回丢状态）。自绘标题栏另有专属通道 `titleAction/wsDropdown/selfInfoReq`（见 docs/details/03 §标题栏通道）。

## 交互反馈
发消息打字机出现；思考先占位再折叠摘要；需授权/提问显示聊天内卡片，经本地应答后 agent 继续，■ 可停止兜底；danger 权限走确认；进行中按钮变 ■；错误给明确人读文案。非法输入/图片就地限制，不静默。

## 用户手册
1. 安装：扩展面板搜本插件（以 `package.json` 的 displayName 为准）或 `code --install-extension <vsix 路径>`；需本机已装并运行 dsh。
2. 打开：点 Activity Bar 的 DSH 图标。
3. 聊天：底部输入/贴图/拖文件/`＋`；`↑` 发送。
4. 模型：🤖 选模型再选推理等级。
5. 权限：🛡 直列预设；danger 需确认。
6. 工作区：点标题栏 📁 或 `> 工作区名` 附近选择；工作区下拉里可搜、展开会话、新建；当前会话标「当前」。
7. 右键代码：处理/提问/@。
8. 完整界面：标题栏「在本地打开/在浏览器打开」。
9. 消费记录：`⋯ → 查看消费记录`（今/昨/周/月分组）。
10. 审批/提问：聊天内直接确认；若卡片未出现，用「在本地打开/在浏览器打开」到 dsh 官方页处理。换工作区=独立会话；升级 dsh 后打不开则重开视图或按 04 核对。
11. 会话模式：输入区层叠图标选择；仅空白/新会话可切换，已有会话只读显示模式。
12. 查看用量/用时：每条回答内容下方默认显示 📊 用量 / ⏱ 用时（带数值），点击向上弹出本轮用量/用时详情（与 dsh 官方口径一致）。提问行悬停只有 复制，回答行悬停才有 复制/重新生成。

> 提示：原生标题栏按钮常驻依赖用户设置 `workbench.view.alwaysShowHeaderActions: true`；未开启时按悬停/激活规则显示。自绘标题栏（`TITLEBAR_MODE='selfDrawn'`）无此限制。
