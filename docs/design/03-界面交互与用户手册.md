# 03 · 界面交互与用户手册

> 阶段：设计/交互/用户 · 维护者：插件维护者

## 布局

侧边栏聊天视图 `dsh.launcher` 顶部为标题栏，下方消息区(flex:1) + 输入区(composer) + 底部 statsbar。

标题栏有两种实现（同一常量 `TITLEBAR_MODE` 切换，当前默认 `nativeTitle`；**不自动判宿主**——nativeTitle 即原生、selfDrawn 即自绘）【v0.1.5 · dsh 0.1.2-rc.1】：
- 原生标题栏：由宿主在 webview 视图头渲染（`menus.view/title`）。宿主渲染得出原生头即生效（默认）；渲染不出（如 sidex 等）则切 `'selfDrawn'`。
- 自绘标题栏：页面内 `#titlebar`，跨宿主通用；渲染不出原生头的宿主用它。

自绘标题栏按钮自左向右：`> 工作区名`（指示，悬停显全称）、spacer、📁（工作区选择）、＋（新会话）、浏览器打开/刷新（仅 DSH 面板打开时）、本地打开、移到编辑器、⋯（消费记录）。👁 关闭侧栏预留但默认隐藏。

| 行首 / 命令菜单 | 输入框行首打 "/" 弹菜单，按上游展示：分组「指令」(commands/list)+「技能」(skills/list)，组内按 host 返回原序**不排序**，客户端贡献 `/model` 追加在指令组末尾（对齐上游「host 原序 + contribution 殿后」）；分派同上游：permission 走可搜索选择弹窗（选即关）、`/model` 走仅模型可搜索列表、无参命令立即执行、带参命令/技能插入 "/name " 且进入参数阶段后菜单不再弹、普通 Enter 即执行；模型图标入口用独立弹窗（分组+推理等级，点选即关）；命令结果一律回显在对话区(成功正常/失败红点红字)，plan 常驻 chip【0.1.6】 |
| 弹层键盘 | 权限/模型(`SearchPicker`)与模式弹窗：↑↓ 移动光标(循环)、Enter 选中、Esc 关闭；打开即定位当前值并聚焦、关闭归还输入框焦点；高亮行随光标滚进列表可视区，搜索框钉住不随列表滚动【2026-09-11】 |
| 消息渲染 | 用户右/dsh 左；markdown 过 DOMPurify；图片内联 max-height 240px；思考折叠「已思考 · N 步 · N 工具」。悬停动作：提问行仅复制；回答行 复制/重新生成 |
| 对话区滚动 | 智能跟随（无缝对话流）：贴底即自动跟随到底；用户向上拖（哪怕 1px，按方向判定）立即解除跟随、不抢阅读位置；回到底部（<24px）恢复；主动发送/重新生成/恢复会话无条件滚到底（scrollPend）【0.1.6 续】 |
| 拖拽添加附件 | **当前不可用**（2026-09-12 真机实测：拖到**输入区里也不生效**）。输入区挂有 `dragover`/`drop` 监听，但 webview 侧拿不到拖拽携带的文件（路径或字节），非图片文件的 `text/uri-list` 路线走不通；图片拖拽同样没反应。**后续方案（延后，见 `tmp/TODO.md`）**：改用拖拽的 `File` 对象读字节（webview 能读内容）→ 交宿主上传 |

| 文件附件（上送） | 输入区「＋」或拖入文件 → **宿主读字节并上传给 dsh**（`POST /api/session/uploadFileBinary`）拿到凭据 `receiptId` → 随消息以 `{type:'file',receiptId}` 发出 → 模型拿到一行 handle 文本（指向 dsh 侧只读副本，自己用文件工具读）。chip 三态：`上传中…` / `上传失败，点击重试`（点正文重试）/ 就绪（`EXT 大小` + 移除）；**未就绪阻止发送**。气泡里显示可点开的文件 chip（编辑器打开）。换会话即清空暂存【v0.1.9】 |
| 输入框 @ 引用 | 行首/空白(含换行)后打 `@`（或 `@"`）弹候选，按查询串实时拉（`fileReferences/list` + `sessionReferenceResolver/candidates`）。候选分两大类别：**「文件与文件夹」**（目录=fileReferences `kind:'directory'`、文件=`file`，图标 codicon `folder-opened`/`file` 区分；目录行右侧 codicon `chevron-right` 可下钻）与**「对话」**（codicon `comment-discussion`）。展示只显短名 + 命中段高亮；层级：`@` 空=顶层、`@x/`=该目录直接子级、纯名字才深层模糊；下钻时弹窗顶部显示面包屑 `工作区 › 目录…`（细线分隔后再列列表）。选中（行身点击/Enter）= 加蓝色引用贴片，贴片**叠在输入框首行行首**（textarea 全宽、仅首行 text-indent 让位，回车/换行回最左；光标在最左时 Backspace 删贴片）；目录右侧 chevron/Tab=钻取（保留 `@目录/` 继续列子项）。发送时 store 把贴片 token（`@rel/path`/空白 `@"…"`/目录带 `/`/会话 `@[label](dsh-session:…)`）作引用行注入 prompt（正文不出 @；dsh 宿主 pre-step 解析），**气泡内引用以蓝色高亮 chip 内联展示（仅真换行才换行）**【2026-09-08】 |
| 消息时钟 | 每条消息动作行左侧时刻，对齐上游日期感知（同日 HH:mm / 今年更早 M月D日 HH:mm / 跨年 Y年M月D日 HH:mm）；来源 = user/assistant 消息 epoch time【0.1.6】 |
| 回复用量/用时 | 每条已完成回答的内容下方**默认常显**两个图标按钮（📊 用量、⏱ 用时，图标旁带数值），点击弹出上游「本轮用量」「本轮用时和速度」弹窗【v0.1.6】（默认向上；消息位于列表最上方、上方放不下时自动翻到消息下方；宽度随内容自适应，提供方/模型等内容短则收窄、长则保持一行封顶 320px）：用量（本轮用量）= 累计投影差分（未缓存输入+缓存读+输出=本轮用量；另列提供方/模型、缓存命中、其中推理）；用时（本轮用时和速度）= 本轮总用时/TPS/TTFT（TTFT、TPS 取累计投影 ttftMs/ttftSteps、decodeMs/decodeTokens 差分；总用时取服务端 turn 事件墙钟）。历史恢复行同样显示（用量=该条 assistant/message 自带 usage；用时由快照事件时间推算）。|
| 已知限制（历史计时） | 历史恢复的 ⏱ 弹窗里 TTFT/TPS **依赖快照保留 `step/start` 与 `text-delta` 时间**；若上游把历史压缩成只剩 `assistant/message`，TTFT/TPS 无数据可算 → 显示 “—”，**不伪造**（用量/总用时仍可显示） |
| statsbar | 底部仅一条上游累计 statsbar（与回复用量相互独立） |

## 消息桥接（webview ↔ 扩展）
消息类型清单不在此登记，**以 `webview/chat/core/protocol.ts` 为单一来源**；宿主侧无同名类型，靠注释与结构对齐，**改协议字段名必须两侧同时改**（否则 postMessage 序列化后对端读不到）。

握手：webview 发 `ready` 后扩展才推 `chatInfo`（避免切回丢状态）。自绘标题栏另有专属通道。

## 交互反馈
发消息打字机出现；思考先占位再折叠摘要；需授权/提问显示聊天内卡片，经本地应答后 agent 继续，■ 可停止兜底；danger 权限走确认；进行中按钮变 ■；错误给明确人读文案。非法输入/图片就地限制，不静默。

## 用户手册
1. 安装：扩展面板搜本插件（以 `package.json` 的 displayName 为准）或 `code --install-extension <vsix 路径>`；需本机已装并运行 dsh。
2. 打开：点 Activity Bar 的 DSH 图标。
3. 聊天：底部输入/贴图/拖文件/`＋`；`↑` 发送。
4. 模型：🤖 选模型再选推理等级（该模型没有默认等级时，等级列表首位是 `Default`，表示用提供方默认）。
5. 权限：🛡 弹层选预设（打开即高亮当前项，↑↓ 选择、Enter 确认、Esc 取消）；danger 需确认。
6. 工作区：点标题栏 📁 或 `> 工作区名` 附近选择；工作区下拉里可搜、展开会话、新建；当前会话标「当前」。新建会话必须归属工作区（规则见第 14 条）。
7. 右键代码：处理/提问/@。
8. 完整界面：标题栏「在本地打开/在浏览器打开」。
9. 消费记录：`⋯ → 查看消费记录`（今/昨/周/月分组）。
10. 审批/提问：聊天内直接确认；若卡片未出现，用「在本地打开/在浏览器打开」到 dsh 上游页处理。换工作区=独立会话；升级 dsh 后打不开则重开视图或按 04 核对。
11. 会话模式：输入区层叠图标选择（↑↓ 选择、Enter 确认、Esc 取消）；仅空白/新会话可切换，已有会话只读显示模式。
12. 查看用量/用时：每条回答内容下方默认显示 📊 用量 / ⏱ 用时（带数值），点击弹出上游「本轮用量」/「本轮用时和速度」详情（默认向上，消息在列表最上方放不下时自动翻到下方；与 dsh 上游口径一致）。提问行悬停只有 复制，回答行悬停才有 复制/重新生成。
13. 行首 `/`：输入框行首输入 `/` 弹指令/技能菜单（按上游展示：分组「指令」「技能」，组内按 host 返回原序；指令如 权限/compact/goal/plan，指令组末尾是 `/model`，技能在下方列出）；选指令执行、选技能插入后发送；命令结果/错误会显示在对话区（成功正常色、失败红点红字），plan 模式时输入区出现 `plan` 小徽标（点击退出）；有会话目标（goal 投影）时输入区常驻 `🎯` goal chip（悬停见全文，chip 内可暂停/继续/清除）。`/export` 会保存会话日志 ZIP 到本地。

14. 会话归属（防「未分组」）：新建会话必须先落在一个工作区——有当前工作区（或能自动取默认：dsh 里 `updatedAt` 最新 / 当前打开的文件夹）直接在其下新建；都没有时点 ＋ 会提示「请先选择工作区」并打开工作区面板，选/建工作区后才开会话，不会自动造出「未分组」会话。在 dsh 上游网页（标题栏「在本地打开/在浏览器打开」）里发起的会话由 dsh 核心按会话 cwd 归组，与侧栏聊天的归属规则相互独立。【v0.1.7 · dsh 0.1.2-rc.1】

> 提示：原生标题栏按钮常驻依赖用户设置 `workbench.view.alwaysShowHeaderActions: true`；未开启时按悬停/激活规则显示。自绘标题栏（`TITLEBAR_MODE='selfDrawn'`）无此限制。
