# 03 · 界面交互与用户手册

> 阶段：设计/交互/用户 · 维护者：插件维护者

## 布局
侧边栏顶部为 VS Code 原生标题栏（`menus.view/title`，视图名 DeepSeek Harness），下方消息区(flex:1) + 输入区(composer) + 底部 statsbar。标题栏图标：工作区、新建、浏览器/本地打开、刷新、关闭侧栏、移到编辑器，`⋯` 收纳消费记录。

## 视觉与组件规范
| 条目 | 规范 |
|---|---|
| 色彩 | 全用 `var(--vscode-*)`，禁硬编码；头像 `--vscode-badge-background`(中性灰无渐变) |
| 图标 | 标题栏 Codicon；输入区权限/模型/模式用内联 SVG currentColor |
| 间距/动效 | `.sel-group` gap 3px；输入栏 8px；消息操作无色仅 hover 变色；尊重 prefers-reduced-motion |
| 弹出面板 | 每图标独立 `#permPopup/#modelPopup/#modePopup`；普通面板锚图标上方，模式弹窗固定定位置顶【v0.1.4 · dsh 0.1.2-rc.1】；点外关 |
| 原生标题栏 | 图标经 `menus.view/title` 注册（navigation 图标 + `1_dsh@6` 收进 `⋯`）；常驻依赖用户设置 `workbench.view.alwaysShowHeaderActions: true` |
| 通用弹窗 | `showDialog()`(modal.ts) 统一确认/提示；danger 确认带 ack 勾选 |
| 输入栏布局 | `#inputbar` 使用 flex 垂直居中，按钮统一 22×22，左侧留白 4px，`+` 与权限间距 6px，整体不靠右侧发送按钮 |
| 输入区边框 | `#inputbox` 常显 1px 边框（主题变量优先，中性灰兜底）；聚焦时换 VS Code focusBorder；`#composer` 无顶部分割线 |
| 图标按钮 | `+`/权限/模型按钮 hover 显示圆角灰底（rgba(128,128,128,0.28)），active 用 0.35；图标以 inline-flex 垂直居中 |
| 会话模式 | 输入区层叠图标弹层；只读（已有会话）时半透明且点击无效；内置模式显示名本地映射，自定义用 dsh name【v0.1.4 · dsh 0.1.2-rc.1 新增】 |
| 发送/停止 | 发送=内联 SVG 细线向上箭头，停止=内联 SVG 方块；按钮 24×24 圆形，flex 居中，CSS 控制 stop 类切换显示 |
| 消息渲染 | 用户右/dsh 左；markdown 过 DOMPurify；图片内联 max-height 240px；思考折叠「已思考 · N 步 · N 工具」 |
| 用量/statsbar | 每条回复显示本轮用量；底部仅一条官方 statsbar |

## 消息桥接（webview ↔ 扩展）
| 方向 | type |
|---|---|
| webview→ext | ready/chatSend/cancel/approvalResponse/questionResponse/questionCancel/chatSelectPermission/chatSelectModel/pickFile/copy |
| ext→webview | chatChunk/chatReasoning/chatActivity/chatApproval/chatQuestion/questionClosed/chatDone/chatHistory/chatInfo/filePicked/draft/clear |

握手：webview 发 `ready` 后扩展才推 `chatInfo`（避免切回丢状态）。

## 交互反馈
发消息打字机出现；思考先占位再折叠摘要；需授权/提问显示聊天内卡片，经 `$events` 本地应答后 agent 继续，■ 可停止兜底；danger 权限走确认；进行中按钮变 ■；错误给明确人读文案。非法输入/图片就地限制，不静默。

## 用户手册
1. 安装：扩展面板搜本插件（以 `package.json` 的 displayName 为准）或 `code --install-extension <vsix 路径>`；需本机已装并运行 dsh。
2. 打开：点 Activity Bar 的 DSH 图标。
3. 聊天：底部输入/贴图/拖文件/`＋`；`↑` 发送。
4. 模型：🤖 选模型再选推理等级。
5. 权限：🛡 直列预设；danger 需确认。
6. 工作区：标题栏「工作区」树；「＋」新建会话（先选工作区）。
7. 右键代码：处理/提问/@。
8. 完整界面：标题栏「在本地打开/在浏览器打开」。
9. 消费记录：`⋯ → 查看消费记录`（今/昨/周/月分组）。
10. 审批/提问：聊天内直接确认；若卡片未出现，用「在本地打开/在浏览器打开」到 dsh 官方页处理。换工作区=独立会话；升级 dsh 后打不开则重开视图或按 04 核对。
11. 会话模式：输入区层叠图标选择；仅空白/新会话可切换，已有会话只读显示模式。【v0.1.4 · dsh 0.1.2-rc.1 新增】

> 提示：标题栏按钮常驻依赖用户设置 `workbench.view.alwaysShowHeaderActions: true`；未开启时按 VS Code 规则悬停/激活才显示。
