# 10 · 对话区信息块「显示模型与规则」（改前必读，防止反复改错）

> **用途**：这是"每个信息块在哪显示、何时显示、如何显示"的**唯一基准**。改任何一处 UI 前**先读这张表**；
> 若确需改变某个行为，**先改本表 + 涉及文件**，避免再出现"收平铺又折叠、hover又done"这类反复。
> **基线：对齐官方 dsh 0.1.2-rc.1**（`dsh_sources_code\0.1.2rc1\deepseek-harness` 源码——插件实际对接版本）。
> 过程折叠/思考行/动作条时机/左下角状态行/瀑布流提问交互，**0.1.2-rc.1 均完整支持**（TurnProcessNodeView/ReasoningRow/MessageIconActions/ChatView.deepDiving/ui-user-questions 齐全）。
> 注：`dsh_sources_code\deepseek-harness`(0.1.5-alpha.1) 与本套显示时序逻辑一致，我此前读 UI 样式用的是 0.1.5-alpha.1 副本，**行为基线应以 0.1.2-rc.1 为准**。

## 0. 总原则
官方把一场 assistant 回复拆成 **「过程内容（可折叠收纳）」+「正文（markdown）」** 两部分，且**进行中展开、定稿收起**。
交互类（提问/审批）走**输入框上方 waterfall 弹窗**，不进对话行；对话行只承载**记录**。

## 1. 信息块显示表（权威）

| 信息块 | 在哪显示 | 何时显示 | 如何显示 | 涉及文件 |
|---|---|---|---|---|
| 系统提示词(agent-instructions) | 左上角**常驻入口** | 会话始终 | 一行(`系统提示词` 图标+标签)，可点开全文；**不入过程链** | `message/SystemPromptEntry.ts` |
| 上下文注入 / 跨会话召回 | **过程折叠内** | 展开才见（不单独平铺） | 一行`上下文注入 · 来源` / `跨会话召回 · 标签`，可展开 | `message/ContextInjectionRow.ts` |
| 思考 | 过程折叠内 | **纯思考且无注入/工具**时思考行平铺在前("一开始是思考")；否则进折叠 | 收起一行`思考 · 摘要`(定稿取首行/流式取 latestLine)，点开全文 | `chain/ReasoningRow.ts` |
| 工具(终端/web/提问卡等) | 过程折叠内 | 展开才见 | 各自卡(等宽命令/来源列表/问答记录)，可展开 | `chain/TerminalBlock.ts` `WebCard.ts` `AskCardBody.ts` |
| 正文(markdown) | 过程折叠**下方** | 流式慢慢出，定稿完整 | markdown，无流式光标(官方无) | `message/AssistantRow.ts` |
| 动作条(复制/重新生成/用量/用时) | 对话行底部 | **回答结束后(done)**才显示，过程不出现 | 复制/重新生成/用量/用时 | `message/meta.ts` |
| 提问**交互** | **输入框上方弹窗**(waterfall) | pending(待答) | 选项/自由输入 + `回答`(选全可提交)/`取消`/`关闭` | `message/QuestionDialog.ts` |
| 提问**记录** | 对话行 | 定稿后 | `提问 · {answered}/{total} 已回答 / 已取消 / 已中断` + 问题↔回复 | `chain/AskCardBody.ts` |
| 左下角状态行 | **左下角** | **运行中(processing)** | `xxxx…` + 小转圈 + ≥15s 时钟 | `message/TurnStatus.ts` |

> 上表"过程折叠内 / 展开才见"都指**外层折叠**（`N 次工具调用 · M 条消息`，见 §2.1）**展开后的明细**；明细里每个过程行**各自还有内层 disclosure**（收起一行 / 点开看内容），是两层。

## 2. 关键规则（反复的根源，一旦改动先更新这里）

### 2.1 过程折叠（外层「N 次工具调用 · M 条消息」）

**作用**：把一轮 assistant 回复的"过程"（思考/工具调用/上下文注入/召回/网页搜索获取/提问记录）收进**一个可折叠的汇总头**，避免过程行全部铺开占空间。点开发开看每个过程的 disclosure 行；进行中默认展开（能看到在干嘛），定稿收起为一行计数。

**触发（是否显示折叠头）**：链里有**工具调用项(ask 提问除外)**、或**上下文注入/召回项(context)**、或**定稿计数 toolCallCount/messageCount>0** → 显示 `N 次工具调用 · M 条消息`，空则兜底 `已思考`。
**纯思考**（无注入/无工具/无计数）→ **不显示折叠头**，思考行直接平铺在前（官方"一开始是思考"）。

**展开/收起时机**：
- **进行中(pending，turn 未 closed)**：默认**展开**（能实时看思考/工具/注入在动）；左下角 `深度求索中…` 状态行做运行指示（对齐官方 `turnClosed`）。
- **定稿(done)**：**收起**成折叠头 `N 次工具调用 · M 条消息`（`message.turnProcess.*`：`{count} 次工具调用` / `{count} 条消息`，分隔 ` · `）；空则 `已思考`(`thoughtForAWhile`)。点开看全部过程行。

**布局/样式**（`styles/chain.css` 的 `.chain-summary` 系）：
| 项 | 值 |
|---|---|
| `.chain` | font 11.5；color descriptionForeground；margin `2px 0 6px` |
| `.chain-summary`(折叠头按钮) | inline-flex；gap 6；padding `2px 6px`；radius 6；font 11.5；cursor pointer；hover 透明底(0.22)；nowrap+keep-all；min-width 0 |
| `.chain-summary-ico`(codicon-sparkle) | 12px；charts-blue |
| `.chain-summary-text` | nowrap；超长 ellipsis；min-width 0 |
| `.chain-summary-chev`(arrow) | 12px；opacity .7；transition transform .12s |
| `.chain-detail`(展开明细) | margin-top 3；flex 列；gap 4 |

**展开后的明细**：过程行**平铺**，各自是 disclosure（收起一行 `标签 · 摘要`，点开看内容）：
- 上下文注入/召回 → `message/ContextInjectionRow`（`上下文注入 · 来源` / `跨会话召回 · 标签`）
- 思考 → `chain/ReasoningRow`（`思考 · 摘要` 一行；流式取 `latestLine` 动态、定稿取 `firstLine`；摘要剥 `**`）
- 工具/终端/web/提问记录 → `chain/ToolRow`（Pwsh→TerminalBlock、web→WebCard、ask→AskCardBody，各自可展开）

> ⚠️ 这是**外层折叠**（整体收起/展开），与每个过程行**自身的 disclosure**（各自收起/展开看详情）是两层：外层折叠控制"整包过程"显隐，内层 disclosure 控制"单个过程"内容。

### 2.2 系统提示词不入链
`form==='instructions'` 的 agent-instructions 在**数据源跳过**（live `contextRow` + 历史 `getSessionMessages`），只走左上角常驻入口；链里只留技能目录/召回/插件/notice 等注入。=> 避免"只含它的链展开为空"。

### 2.3 提问分离「交互」与「记录」
- 交互（选/提交/取消/关闭）→ 输入框上方 waterfall 弹窗（`pendingQuestion` 信号驱动）。
- 对话行提问卡只做记录；**提问不参与过程折叠**（`hasFold` 排除 ask_user_question），纯提问 turn 平铺显示问行。

### 2.4 动作条时机
复制/重新生成/用量/用时**仅回答结束后(done)**渲染（不是 hover 常驻——那是官方 `data-actions-reveal`，本插件按用户要求定稿后现）。
